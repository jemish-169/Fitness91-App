# Fitness91

## Features

- **User Authentication**  
  - Secure and efficient login/signup using Supabase Auth.  

- **Daily Fitness Modules**  
  - **Gym Training**: Tailored daily workout plans.  
  - **Face Exercise**: Simple facial workouts to relax and tone.  
  - **Diet Planning**: Suggested meals and hydration tracking.  
  - Daily plans are fetched from Supabase based on the current weekday.  

- **Progress Tracking & Visualization**  
  - Track completed exercises and diet goals.  
  - Visual feedback with color-coded progress indicators.  
  - View historical performance on a daily and monthly basis.

- **Dynamic Dashboard**  
  - Highlights today’s plan and current progress.  
  - Module-wise and overall progress displayed clearly.  
  - Adaptive UI with support for dark, light, and system themes.

## Technology Stack

- **Android (Kotlin)** – Native Android development using Jetpack Compose  
- **Supabase** – Backend-as-a-service for authentication, real-time data sync, and database  
- **Jetpack Compose** – Declarative UI toolkit for clean, efficient layouts  
- **Coroutines** – Managing background tasks smoothly  
- **Hilt** – Dependency injection for modular, testable architecture  
- **MVVM + Clean Architecture** – Ensures a scalable, maintainable, and test-friendly codebase  
- **Material Design** – Follows Google’s UI/UX guidelines for intuitive design  
- **Animations** – Enhances user experience with meaningful transitions and effects
